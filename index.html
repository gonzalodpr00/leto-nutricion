Herramientas avanzadas

Privacidad y almacenamiento

Perfil, meta energética, historial y diario se guardan automáticamente en este navegador. No se publican en GitHub Pages. Las búsquedas de productos sí se envían a fuentes externas. Cerrar Safari no borra los datos; eliminar los datos del sitio sí puede hacerlo. Si borras los datos del sitio o cambias de dispositivo, puedes recuperar tus datos con la copia de seguridad. Guarda una copia periódicamente en Archivos o iCloud Drive.

Precisión: los datos dependen de una API independiente. Comprueba la etiqueta del envase cuando necesites exactitud; NutriDía no inventará valores nutricionales que falten.
NutriDía es una herramienta personal de cálculo nutricional, no un producto oficial de Mercadona ni un servicio médico.
