Base de datos de alimentos

NutriDía busca en el catálogo guardado, en MercaAPI y en Open Food Facts. Open Food Facts es una base colaborativa de productos envasados; la cobertura y exactitud dependen de los datos aportados por sus usuarios.

Privacidad y almacenamiento

Esta versión guarda perfil, alimentos registrados y objetivos en el almacenamiento local de Safari de este iPhone. No se suben a GitHub Pages. GitHub aloja los archivos de la aplicación, no tu diario personal. Las consultas de productos se envían a las fuentes externas para buscar alimentos.

Si borras los datos de Safari, cambias de navegador o de dispositivo, podrías perder los registros. Utiliza la copia de seguridad de Mi perfil para trasladarlos.

Uso en iPhone

Diseño adaptado a pantalla pequeña, controles con tamaño táctil y navegación por pestañas. El zoom del sistema puede limitarse para evitar que la interfaz se descoloque; puedes usar el tamaño de texto del sistema cuando sea compatible.

NutriDía es una herramienta personal de cálculo nutricional, no un producto oficial de Mercadona ni un servicio médico. Fuentes: MercaAPI (no oficial) y Open Food Facts, base colaborativa de productos alimentarios. Tus registros se guardan en el almacenamiento local de este navegador. Exporta una copia periódicamente si quieres conservarlos o cambiar de dispositivo.
